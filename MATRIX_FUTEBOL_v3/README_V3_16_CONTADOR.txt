MATRIX FUTEBOL V3.16 - CONTADOR CORRIGIDO

PROBLEMA CORRIGIDO
Na V3.15, o card "Auto DEMO" mostrava o número de candidatos/oportunidades
disponíveis naquele instante. Isso podia causar, por exemplo:
- 7 apostas já feitas
- 6 oportunidades ainda disponíveis
- painel mostrando 6 no card Auto DEMO

AGORA
- "Minhas apostas" = todas as apostas registradas no histórico.
- "Auto DEMO feitas" = quantidade real de apostas automáticas registradas.
- "Oportunidades agora" = quantidade de candidatos disponíveis neste momento.
- O resumo mensal também mostra "Auto DEMO feitas".

Nenhuma aposta antiga é apagada nesta atualização.
Os dados continuam sendo lidos do mesmo localStorage matrix_bets_v33.
