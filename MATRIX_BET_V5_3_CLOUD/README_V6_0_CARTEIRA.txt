MATRIX BET V6.0 - CARTEIRA

Incluído:
- usuário solicita depósito;
- usuário solicita saque por chave PIX;
- extrato de solicitações;
- ADM recebe depósitos/saques;
- ADM aprova ou rejeita;
- aprovação de depósito credita saldo;
- aprovação de saque debita saldo;
- evita saque acima do saldo disponível;
- auditoria das decisões.

Observação: nesta versão o fluxo financeiro é administrativo/manual. Não há integração automática com banco, PIX ou gateway de pagamento.
