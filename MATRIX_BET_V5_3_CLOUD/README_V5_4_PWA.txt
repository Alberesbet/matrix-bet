IMPORTANTE SOBRE FACEBOOK/INSTAGRAM
Navegadores internos de alguns apps podem não disparar o prompt nativo de instalação.
Nesses casos o botão informa para abrir no Chrome e usar “Instalar app/Adicionar à tela inicial”.
A opção CONTINUAR PELA WEB funciona normalmente.

Esta versão continua demonstrativa e não habilita PIX, saque ou dinheiro real.
