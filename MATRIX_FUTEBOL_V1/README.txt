MATRIX - FUTEBOL V1

Projeto novo e independente do MATRIX BET.

- Consulta jogos do dia na SportMonks.
- Consulta odds pré-jogo por partida.
- Analisa mercado 1X2 (Casa/Empate/Fora).
- Filtra por odd e probabilidade normalizada.
- Registra os sinais em data/historico.csv.
- Repete a análise automaticamente a cada 5 minutos.
- Modo inicial: SIMULAÇÃO.

COMO INICIAR NO WINDOWS
1. Instale Python 3.11 ou superior.
2. Na pasta: pip install -r requirements.txt
3. PowerShell: $env:SPORTMONKS_TOKEN="SEU_TOKEN"
4. Execute: python matrix_futebol.py

IMPORTANTE
Não coloque seu token dentro do código nem envie a chave para outras pessoas.
Esta V1 não envia apostas reais. Para uma futura execução real é necessária uma API oficial/autorizada da operadora.
Os filtros estatísticos não garantem lucro.
